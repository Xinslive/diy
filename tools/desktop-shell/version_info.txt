# docs/Windows打包exe可行性研究.md「代码签名」一节。
#
# ⚠️ 发布前请把 CompanyName / LegalCopyright 换成**真实的发行主体**。
#    保留占位值不影响功能，但会让误报申诉更难通过。
#
# 2026-03-01 起，代码签名证书的最长有效期约 460 天（约 15 个月），
# 比以前的 39 个月短了一截 —— 续签节奏要按这个算。
#
# 版本号在这里出现三处（filevers / prodvers / StringStruct），
# 改版本时**三处一起改**，漏一处就会在「属性 → 详细信息」里显示
# 一个对不上的版本。
